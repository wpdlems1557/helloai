# 치지직 트래커 (Chzzk Tracker) - 실시간 스트리머 방송 모니터링 서비스

'치지직 트래커(Chzzk Tracker)'는 치지직(CHZZK) 플랫폼에서 활동하는 여러 스트리머의 방송 상태를 한곳에서 확인하고 관리할 수 있는 실시간 방송 모니터링 서비스입니다.

사용자가 관심 있는 스트리머를 등록하면 방송 시작 여부, 방송 제목, 시청자 수 등의 정보를 실시간으로 확인할 수 있으며, 효율적인 방송 시청 환경을 제공하도록 설계하였습니다.

이 프로젝트는 Next.js App Router, TypeScript, Tailwind CSS를 활용하여 설계되었으며, Vercel 서버리스 환경에서 즉시 배포하여 서비스할 수 있도록 구성하였습니다.

🚀 프로젝트 개발 과정
[Step 1] GitHub 저장소 생성 및 로컬 환경 구성

GitHub 저장소를 생성한 후 프로젝트를 로컬 환경으로 복제하여 개발을 진행하였습니다.

git clone https://github.com/본인계정/chzzk-tracker.git

cd chzzk-tracker

npm install

의존성 패키지를 설치한 후 개발 서버를 실행하여 기능을 테스트하였습니다.

npm run dev
[Step 2] 방송 데이터 수집 기능 구현

치지직 플랫폼의 데이터를 활용하여 실시간 방송 정보를 수집하는 기능을 구현하였습니다.

수집 대상 정보는 다음과 같습니다.

스트리머 이름
방송 진행 여부
방송 제목
카테고리
시청자 수
방송 시작 시간

또한 사용자가 원하는 스트리머를 등록하고 목록으로 관리할 수 있도록 기능을 구현하였습니다.

[Step 3] 서비스 배포

Vercel을 활용하여 프로젝트를 배포하였습니다.

배포 과정은 다음과 같습니다.

GitHub 저장소와 Vercel 연동
환경 변수 설정
Deploy 실행
서비스 URL 생성

이를 통해 누구나 웹 브라우저에서 서비스를 사용할 수 있도록 구성하였습니다.

🛠️ 주요 기능 소개
대시보드 (Dashboard)

사용자가 등록한 스트리머들의 방송 상태를 한눈에 확인할 수 있습니다.

실시간 방송 추적 (Live Tracker)

방송 시작 여부를 실시간으로 확인하고 최신 정보를 자동으로 갱신합니다.

스트리머 관리 (Streamer Management)

관심 있는 스트리머를 추가, 삭제 및 즐겨찾기하여 관리할 수 있습니다.

방송 정보 시각화 (Broadcast Visualization)

방송 제목, 시청자 수, 카테고리 등의 정보를 카드 형태로 보기 쉽게 제공합니다.

자동 새로고침 기능 (Auto Refresh)

일정 시간마다 데이터를 자동으로 갱신하여 항상 최신 상태를 유지합니다.

관리자 기능 (Admin Console)

관리자는 등록된 스트리머 목록과 서비스 운영 상태를 관리할 수 있도록 구성하였습니다.
